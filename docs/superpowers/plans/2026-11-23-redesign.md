# Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the game its "letter tiles and a lit fuse" look: three themes, the Lexend and Rubik fonts, a new animated bomb, 60 emoji avatars, the circle on every screen, live typing with simple masking, and the new lobby and results screens. Game rules don't change.

**Architecture:** This keeps the current shape (approach A in the spec). The server gets six small view and protocol additions, all test-first.
- The browser renderers stay pure functions that return escaped HTML, and only the `*-page.js` files touch the DOM.
- Colours live only in `public/app/themes.css`. The bomb lives only in `public/app/bomb.js`.
- Animations survive re-renders because the pages pass "elapsed time" into the pure renderers, which turn it into a negative `animation-delay`. Nothing in the DOM has to be preserved between renders.

**Tech Stack:**
- TypeScript (Node 24, `tsx --test`) for the engine and server.
- Plain ES modules with JSDoc and `checkJs` for the browser, with no build step.
- Playwright (pre-installed at `/opt/npm-tools/node_modules/playwright`) for the end-to-end tests and screenshots.

**Spec:** `docs/superpowers/specs/2026-11-23-redesign-design.md`. Also read `docs/design-principles.md` and `CLAUDE.md` before starting.

## Global Constraints

- **Game rules stay the same.** Rules, timings, scoring, prompts and word lists don't change. The server changes are only the six in spec section 7.
- **Privacy:** no colour, font or emoji is loaded from outside the site. No analytics, cookies or logging of nicknames or words.
- **Escaping:** every piece of player text in new markup goes through `esc()`. Nicknames and words are split into characters with `Array.from()` (code points), never `.split("")`.
- **The projector and the ⚙ overlay never show** scores, ghost points, tokens or the passcode. The projector and player views carry no ghost points at all.
- **Colours:** no colour value (`#hex`, `rgb(`, `hsl(`) appears outside `public/app/themes.css`. Everything uses the named colours.
- **Theme ids:** `workshop` (the default), `enamel` and `night-fuse`. Labels: "Workshop", "Enamel", "Night fuse".
- **Workshop colours** (from the spec), using these exact variable names:

  | Variable | Workshop |
  |---|---|
  | `--stage` | `#1F2A36` |
  | `--tile` | `#E8C48C` |
  | `--tile-edge` | `#B48A4E` |
  | `--tile-ink` | `#2B1D10` |
  | `--bomb` | `#C8243A` |
  | `--bomb-shade` | `#8E1626` |

  The builder chooses the extra variables `--panel`, `--answered`, `--refusal`, `--turn` and `--bomb-rim`.
- **Enamel colours:**
  - `--stage #243244`, `--tile #F3F0E8`, `--tile-ink #1A2430`, `--tile-edge #C9C3B4`
  - `--bomb #1A2430`, `--turn #FF5A4E`, `--spark #FFD23F`, `--names #EEF2F7`, `--muted #93A1B3`
- **Night fuse colours:**
  - `--stage #16202A`, `--tile #DCE6E1`, `--tile-ink #13201B`, `--tile-edge #A9BAB2`
  - `--bomb #0E141A`, `--turn #FFC23D`, `--spark #E8364F`, `--names #E8EEF0`, `--muted #7F8E99`
  - The builder fills in the missing ones.
- **Bomb:** it stays dark in Enamel and Night fuse, with a light `--bomb-rim`. The rim must be at least 3:1 against `--stage` in every theme, Workshop included, because Workshop's red is only 2.6:1.
- **Fonts:**
  - Lexend 400 and 600 for reading text.
  - Rubik 800 for tiles, names, headings and the room code.
  - Stored as `.woff2` files in `public/fonts/`, with `font-display: swap`. The Latin subset must include æ, ø and å.
- **Emoji:**
  - Exactly 60, indexed 0–59. One per player, unique within a room.
  - Twemoji SVGs from `@twemoji/svg@15.0.0`, credited "Emoji: Twemoji (CC BY 4.0)".
  - No faces with skin tones, no flags, and none of 🍆, 🍑, 💩 or 🖕.
- **Motion:** boldness belongs to the bomb only: flame, arrow swing, explosion and fuse. The only other animation is the lobby join pop.
  - Under `prefers-reduced-motion: reduce`, the flame is still, the arrow jumps, the explosion is a brief static flash, and the pop doesn't happen.
- **Timings:** arrow swing 600 ms (`ARROW_SWING_MS`), explosion 1200 ms (`EXPLOSION_MS`).
- **Two rings:** when more than 20 players are on the circle.
- **Live typing:** on by default. Help text: "Show the current player's typing on all screens." The mask text is exactly `★★★★`.
- **Copy:** an avatar refusal reads "Taken, pick another". Changing an avatar during a game reads "You can change your emoji in the lobby".
- **Process:**
  - Test-first for every behaviour change: watch it fail, then make it pass.
  - After every task, `npm test` and `npx tsc -p tsconfig.json` both pass.
  - After every task that changes `public/`, `npm run test:e2e` passes too.
  - Commit after each task. Push only to the working branch, never to `main`, and never on a lesson day.

## Review Focus

1. **Characters in nicknames:** emoji, æøå, `<script>` and 16-character names in the new tiles, seats and results. They must render escaped, whole and unbroken. Tests are added in Task 9.
2. **32 players on a 1366×768 student screen and on the projector:** seats stay inside the circle area, two rings don't overlap, and the bomb stays clear. A geometry test is added in Task 9, plus a screenshot check in Task 14.
3. **A theme value the client doesn't know** (an old server, or a tampered message): the page falls back to Workshop and never puts the raw value into markup. Tested in Task 2.
4. **Two students racing for the same emoji, and junk avatar messages** (`"3"`, `-1`, `60`, `2.5`, `NaN`, sent during a game): the second student gets "Taken", junk is dropped, and nobody's avatar changes during a game. Tested in Tasks 6 and 7.
5. **A projector or student refresh mid-game:** the first view after a refresh must not swing the arrow from 0°, must not replay an old explosion, and must still show every player's last word, which the server holds. Tested in Tasks 4 and 10.

**Interfaces:**
- Consumes: `lastEvent` on projector and player views (Task 3)
- Produces: in `circle-geometry.js`:
  - `seatPosition(i: number, n: number): { left: number, top: number, angle: number, ring: 0 | 1 }`. `left` and `top` are percentages of the circle box, and `angle` is in degrees, 0 = straight up, clockwise.
  - For `n <= 20`, every seat has ring 0 at radius 42 % horizontally and 40 % vertically (the current values).
  - For `n > 20`, even `i` is ring 0 (outer) and odd `i` is ring 1 (inner, radius 30 % and 28 %).
  - `arrowAngle(view: any): number | null` is the `angle` of `view.mode.current` among the seated players (see `seatedPlayers`), or `null` when there's no `current`.
  - `seatedPlayers(view: any): any[]`: in Classic, `view.mode.seats` mapped to players; otherwise the non-spectator players in `view.players` order.
- Produces: in `bomb.js`:
  - `ARROW_SWING_MS = 600` and `EXPLOSION_MS = 1200`.
  - `BOMB_CSS: string`, which holds every bomb style, keyframe and reduced-motion rule, using only `var(--…)` colours.
  - `renderBomb(state: BombState, inner: string): string`.

```js
/** @typedef {{
 *   lit: boolean,                                            // false: no flame, fuse unlit (lobby)
 *   arrow: null | { from: number, to: number, elapsedMs: number },  // degrees; null = no arrow (lobby, Everyone)
 *   countdownMs: number | null,                              // visible timer → number on the bomb with data-countdown
 *   fuse: null | { totalMs: number, elapsedMs: number },     // visible timer → fuse burns down over totalMs
 *   explosion: null | { elapsedMs: number },                 // within EXPLOSION_MS of an explosion
 * }} BombState */
```

  - The returned markup keeps `data-bomb` on the root and `data-countdown` on the number, so the existing 50 ms loops still update them and toggle `urgent`.
  - `inner` is placed on the bomb body. Task 11 puts the prompt tiles there.
  - The arrow is drawn rotated with `--from` and `--to` custom properties, plus `animation-delay: -${elapsedMs}ms`. When `elapsedMs >= ARROW_SWING_MS`, it's drawn at `--to` with no animation.
- Produces: in `motion.js`:
  - `createMotion(now: () => number)` returns `{ view(v: any): void, bombState(countdownMs: number | null, lit: boolean): BombState, popElapsed(pid: string): number | null, busy(): boolean }`.
  - `busy()` is true while a swing, an explosion or a pop is still running, so the page keeps redrawing about every 100 ms.
  - The fuse's `totalMs` is the remaining time first seen for a prompt (keyed on prompt text, type and round).
  - `popElapsed` reports a time only for players first seen **after** the first view, so a refresh doesn't pop everyone again.

- Produces: in `tiles.js`:
  - `tiles(text: string, cls?: string): string`: one `<span class="tile">` per code point (`Array.from`), each escaped, wrapped in `<span class="tiles {cls}">`. Whitespace becomes a gap span, never an empty tile.
  - `matchRange(word: string, prompt: { text: string, type: string }): [number, number] | null`, in code-point indexes, compared case-insensitively. Contains means the first occurrence, starts means the beginning, and ends means the end.
  - `matchedTiles(word, prompt): string`: the same as `tiles`, but tiles inside `matchRange` get class `tile matched`. They're drawn raised and in `--spark`, so the match is shown by shape and colour.
- Produces: in `render-circle.js`, `renderCircle(view: any, opts: { compact: boolean, bomb: BombState, centre: string, popElapsed?: (pid: string) => number | null }): string`. Each seat is `<div class="seat …" style="left:…%;top:…%">` containing:
  - `avatarImg(p.avatar)`, the name in `.name` and the hearts in `.lives` (or "out");
  - the offline mark as now;
  - `.answered` ✓ when `p.answered`;
  - for the current player, when `view.typing` is a string, `.typing` with tiles plus a `.caret`;
  - otherwise, when `p.lastWord` is set, `.last-word` with `matchedTiles(p.lastWord.word, p.lastWord.prompt)`.

  The seat classes:
  - `on` for the current player, which is also drawn larger, so the turn isn't shown by colour alone;
  - `out` when the player is knocked out;
  - `ring-1` for the inner ring;
  - `pop` with a negative `animation-delay` when `popElapsed` returns a number;
  - `small` when there are more than 20 seats.

  The centre is `renderBomb(opts.bomb, opts.centre)`. The whole circle has class `circle` plus `compact` when `opts.compact`.
